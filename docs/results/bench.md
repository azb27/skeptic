## How to read this
- **Ground truth is by construction.** Markets are synthetic; edges and flaws are planted; an oracle confirms every SURVIVES case passes all checks and every flaw case is what it says (`bench/build.py`).
- **The rules-only baseline sees the same check results** as the agents (shared cache), so differences come from reading code and notes, not from different numbers.
- **Leaks on null markets** are also caught by the backtest (no real edge), so a verdict can be right for the wrong reason. The *right reason* column and the leak-line column separate those.
- **One run per configuration.** Model sampling varies between runs; small differences are inside the intervals.
- **The bench measures the planted classes only.** A pass here says nothing about flaws outside them.
- Bench corrections found while running it are logged in [`evals/CORRECTIONS.md`](../../evals/CORRECTIONS.md).
