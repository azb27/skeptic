Instructions for Claude Code working in this repo. Read `SPEC.md` first; it is the plan of record. The current phase is the first unchecked box in SPEC §7.

## What this is
Skeptic: a research agent that tries to kill trading strategies, plus a bench of strategies with planted flaws and planted real edges that measures how well it does. The portfolio value is the **bench results** and the **case-study audit**, not the agent's prose.

## Commands
```bash
pip install -e ".[dev]"                 # or: uv sync
python -m skeptic.data                  # download XAUUSD 1-minute bars (~150 MB) -> data/xauusd_bars.parquet
pytest -q                               # tests (data-dependent tests skip without the parquet)
ruff check . && ruff format --check .
```
Install the secret guard once per clone: `ln -sf ../../scripts/pre-commit .git/hooks/pre-commit`.

## Hard rules
1. **The LLM never produces a number.** Every statistic in a verdict comes from a check in `src/skeptic/checks/`. The agent chooses checks, reads code, and writes the verdict.
2. **Skeptic can only fail to reject.** The strongest verdict is "SURVIVES CHECKS". Never write "profitable", "validated" or "works" about a strategy.
3. **Costs are explicit.** No engine or check defaults to a zero spread. Gross numbers are labelled gross.
4. **The bench manifest (`bench/manifest.json`) is ground truth.** Only `tests/` and `evals/` may read it. The agent's tools must never reach it.
5. **The agent is read-only.** It reads the case folder and runs checks. No tool writes files, edits strategies, or searches parameters.
6. **Aziz's harness code is private.** It lives in `/private/` (git-ignored). Publish findings and short excerpts, never the harness.
7. **Numbers in docs come from runs.** Results files are generated by scripts, with the command written above each table.
8. Record decisions that would be expensive to reverse as ADRs in `docs/adr/` (`/adr <title>`).

## Conventions
- Python 3.11+, type hints, `ruff` (pinned), `pytest`. Seeds come from `config.SEED`.
- Times are UTC. A bar is labelled by its open time; decisions happen at its close.
- Small commits, one concern each, imperative mood. When a phase finishes: tick it in SPEC §7 with evidence.
